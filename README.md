# Demo Web Shop Automation

## Project Overview

To test the functioning of web applications and API solutions, this project integrates UI Automation Testing with API Testing. 

Postman is used to develop and run API test cases, and Playwright is used for UI automation testing. Newman is used to create HTML test reports and run the Postman collection from the command line.

Additionally, the project uses npm scripts to run API and UI tests independently or in tandem.

This project uses Postman and Newman for API testing and Playwright for UI automation to test the Demo Web Shop website and the JSONPlaceholder Users API.

## Tech Stack

- Playwright – UI automation testing
- Postman – API test creation and execution
- Newman – Running Postman collections from the command line
- Newman HTML Extra Reporter – Generating HTML test reports
- Node.js – JavaScript runtime
- npm – Package management and test execution
- JavaScript – Writing automation test scripts
- Allure Report – Generating and viewing UI test execution reports
- Page Object Model (POM) – Organizing UI test code by separating page elements and actions from test cases

## Setup

### 1. Install the prerequisites

Install Node.js, npm, Git, and Java (Allure needs Java to build its reports). Verify the installations by running:

```bash
node --version
npm --version
git --version
java -version
```

### 2. Clone the repository

Clone the project from GitHub using:

```bash
git clone https://github.com/sammy-sad/demo-web-shop-automation.git
```

Navigate to the project directory:

```bash
cd demo-web-shop-automation
```

### 3. Install project dependencies

Installing all the required packages listed in `package.json`:

```bash
npm install
```

### 4. Install Playwright browsers

Downloading the Chromium browser required for Playwright testing:

```bash
npx playwright install chromium
```

## Running the Tests

### 1. Run UI scenarios individually

The UI tests create their own user: Q2 and Q3 register a new account on every run, so no account needs to be set up beforehand.

Scenario 1 – Run the first UI test:

```bash
npx playwright test tests/q1-invalid-login.spec.js --project=chromium
```

This test checks that logging in with invalid credentials is rejected and an error message is shown.

Scenario 2 – Run the second UI test:

```bash
npx playwright test tests/q2-register-cart.spec.js --project=chromium
```

This test checks that a new user can register and then add a product to the cart.

Scenario 3 – Run the third UI test:

```bash
npx playwright test tests/q3-e2e-order.spec.js --project=chromium
```

This test checks the full end-to-end flow of placing an order, from selecting a product through checkout.

### 2. Run API tests

Run the Postman collection through Newman using:

```bash
npm run test:api
```

This executes the Users API collection and generates an HTML report at `newman-report/report.html`.

### 3. Run all tests in sequence

Run both UI and API tests using:

```bash
npm run test:all
```

This runs the UI tests first, then the API tests, and finally builds the Allure report. To open the Allure report in your browser, run `npm run test:report`.

## Reports

- **Playwright HTML Report:** Generated by `npm run test:ui`, saved in `playwright-report/`. Open it using `npx playwright show-report`.
- **Allure Report:** Generated using `npm run test:report`, which builds the report and opens it in the browser.
- **Newman HTML Report:** Generated by `npm run test:api`, saved at `newman-report/report.html`. Open the HTML file in a browser to  view the report.
